关于交付部知识库系统

系统简介

本系统是为公司交付部设计的知识管理和IT资产管理系统，旨在：

  • 记录和共享技术问题和解决方案
  • 管理虚拟机和宿主机信息
  • 提高团队协作效率
  • 沉淀团队知识资产
开发团队

交付部全体成员

主要功能
知识库管理

文章创建、编辑、搜索、分类、标签

虚拟机管理

宿主机和虚拟机信息记录与管理

技术架构
后端框架 Django 4.2 + Python 3.13
数据库 MySQL 8.0 (使用pymysql驱动)
前端 Bootstrap 5 + Font Awesome
富文本编辑器 CKEditor 6.7.3
web容器 Nginx 1.20.1
